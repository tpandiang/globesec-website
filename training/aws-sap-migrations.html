7 RsFundamental
Q1.Which migration strategy is nicknamed lift and shift, moving servers to AWS as they are with no cloud optimization?
AReplatform
BRefactor
CRelocate
DRehost
✓ Correct: D. Rehost

How to think about it: Lift and shift = Rehost. Lift and reshape = Replatform.

Why D is correct: Rehost moves machines (physical, virtual or another cloud) to AWS unchanged, often with Application Migration Service.

Why the others are wrong:
A) Replatform — Replatform makes a few cloud optimizations, such as a managed database, so it is lift and reshape.
B) Refactor — Refactor redesigns the application with cloud-native features, which is the opposite of moving it as is.
C) Relocate — Relocate moves workloads at the hypervisor or account level, such as VMware to VMware Cloud on AWS.

Q8.On-premises servers need to read and write objects in an S3 bucket as files over NFS or SMB, with recently used data cached locally. Which gateway fits?
ATape Gateway
BAmazon S3 File Gateway
CVolume Gateway in cached mode
DAmazon EFS mounted over VPN
✓ Correct: B. Amazon S3 File Gateway

How to think about it: Files (NFS/SMB) stored as S3 objects = S3 File Gateway.

Why B is correct: S3 File Gateway exposes buckets as NFS or SMB shares, stores each file as an S3 object and caches recent data locally.

Why the others are wrong:
A) Tape Gateway — Tape Gateway presents a virtual tape library for backup software, not file shares.
C) Volume Gateway in cached mode — Volume Gateway presents iSCSI block volumes, not file shares backed by S3 objects.
D) Amazon EFS mounted over VPN — EFS is a native NFS file system, and its data is not stored as S3 objects.

DJoin the gateway to Microsoft Active Directory

ATo an EBS snapshot linked to the gateway

Q16.An admin restores an older version of an object directly in the versioned S3 bucket behind an S3 File Gateway. On-premises users still see the old file. What is missing?
ACalling the RefreshCache API on the gateway file share
BTurning on S3 Transfer Acceleration
CRebooting every NFS client
DEnabling S3 Cross-Region Replication on the bucket
✓ Correct: A. Calling the RefreshCache API on the gateway file share

How to think about it: Changes made in S3 behind the gateway = call RefreshCache so the share sees them.

Why A is correct: The gateway does not watch the bucket for outside changes. RefreshCache updates its listing so clients see the restored version.

Why the others are wrong:
B) Turning on S3 Transfer Acceleration — Transfer Acceleration speeds uploads over long distances and does not affect cached metadata.
C) Rebooting every NFS client — The stale view lives in the gateway cache, so restarting clients does not help.
D) Enabling S3 Cross-Region Replication on the bucket — Replication copies objects to another bucket; it does not refresh the gateway's view.

Q17.Files written through an S3 File Gateway must be kept in a write once, read many (WORM) state for compliance. What should you configure?
AS3 Object Lock on the bucket behind the gateway
BAWS Backup Vault Lock
CAn S3 Lifecycle rule to Glacier Deep Archive
DA read-only NFS export on the gateway
✓ Correct: A. S3 Object Lock on the bucket behind the gateway

How to think about it: File Gateway + WORM = S3 Object Lock on the bucket (edits become new versions).

Why A is correct: With Object Lock, changes made through the share create new object versions while the locked original stays unchanged.

Why the others are wrong:
B) AWS Backup Vault Lock — Vault Lock protects backups in AWS Backup vaults, not live objects written through the gateway.
C) An S3 Lifecycle rule to Glacier Deep Archive — Lifecycle rules change storage class and cost; they do not stop deletion or overwrite.
D) A read-only NFS export on the gateway — A read-only share blocks writes entirely, and it is not a retention control on the stored data.

Q20.Copying to a Snowball Edge through its file interface is slow. Which change usually increases throughput the most?
AUse the Amazon S3 adapter with parallel writes
BCopy one file at a time to avoid contention
CRun antivirus scans on files during the copy
DRoute the copy through more network hops
✓ Correct: A. Use the Amazon S3 adapter with parallel writes

How to think about it: Faster Snowball copies = use the S3 adapter, parallel writes, and batch small files.

Why A is correct: The S3-compatible endpoint is typically several times faster than the file interface, and parallel copies add more.

Why the others are wrong:
B) Copy one file at a time to avoid contention — Serial copying wastes the device's bandwidth; multiple writers at once are faster.
C) Run antivirus scans on files during the copy — Touching files during transfer slows it down and is listed as something to avoid.
D) Route the copy through more network hops — Extra hops add latency; connecting the device directly is better.

DSchema conversion
✓ Correct: B. Change data capture (CDC)

Q25.A company migrates from Microsoft SQL Server to Aurora PostgreSQL. What must happen to tables, views and stored procedures?

CNothing; DMS copies them as is
DExport them with RDS native backup and restore
