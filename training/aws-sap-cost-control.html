Q1.Teams tagged every resource with CostCenter, but the tag never shows up as a column in billing reports or as a Cost Explorer grouping. What is missing?
AAdding the tag again with the Tag Editor
BTurning on AWS Config recording for tags
CRenaming the key so it starts with aws:
DActivating CostCenter as a cost allocation tag
✓ Correct: D. Activating CostCenter as a cost allocation tag

How to think about it: A tag only reaches billing once it is activated as a cost allocation tag.

Why D is correct: User-defined tags must be activated for cost allocation before they appear in cost reports and Cost Explorer.

Why the others are wrong:
A) Adding the tag again with the Tag Editor — Re-tagging changes nothing; the tag is not yet enabled for billing.
B) Turning on AWS Config recording for tags — Config records resource configuration, not billing dimensions.
C) Renaming the key so it starts with aws: — The aws: prefix is reserved for tags AWS generates; you cannot create it.
