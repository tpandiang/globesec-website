MetricsFundamental
Q1.An EC2 instance uses default monitoring. How often does it send metrics such as CPUUtilization to CloudWatch, and how do you make it every minute?
AEvery minute; enable high-resolution mode for 1-second data
BEvery 15 minutes; install the agent for 5-minute data
CEvery 10 seconds; nothing more granular exists
DEvery 5 minutes; enable detailed monitoring for 1-minute data
✓ Correct: D. Every 5 minutes; enable detailed monitoring for 1-minute data

How to think about it: EC2 basic = 5 min (free); detailed = 1 min (paid).

Why D is correct: Basic monitoring publishes at 5-minute intervals, and detailed monitoring raises that to every minute for a charge.

Why the others are wrong:
A) Every minute; enable high-resolution mode for 1-second data — Default EC2 metrics are 5-minute, and built-in EC2 metrics cannot be made 1-second.
B) Every 15 minutes; install the agent for 5-minute data — Neither interval is right; basic is 5 minutes and detailed is 1 minute.
C) Every 10 seconds; nothing more granular exists — Ten-second granularity applies only to high-resolution custom metrics.

ATreat missing data as breaching
BSet datapoints to alarm to 3 and evaluation periods to 5
CSwitch the metric to high resolution
DPut the alarm inside a composite alarm alone
✓ Correct: B. Set datapoints to alarm to 3 and evaluation periods to 5

BThey are two names for the same object
CLog streams are only used for VPC Flow Logs
DA log stream holds many log groups
✓ Correct: A. A log group holds many log streams, each from one source

Why A is correct: Groups usually represent an application, and each instance, container or file writes its own stream.
